Frequently Asked Questions

1- What does this application do?

This application automatically analyzes chest X-rays and draws bounding boxes around suspicious opacities. Radiologists can then review the highlighted areas and use their clinical judgment to make the final diagnosis. This is a free diagnostic support tool.

2- How is it used?

- Upload one or more chest X-rays (in dicom, png, or jpg format).
- Once your images are submitted, they are automatically analyzed.
- A list of image names is displayed.
- The number of suspicious opacities is also displayed.
- Click on an image name to view the image with the drawn bounding boxes.
- Click anywhere on the image to hide or show the bounding boxes.

A few example chest X-rays are available in the folder named "example_Lujain_images" for testing. You can use these images.

3- How can I zoom in on the image?

To enlarge the image, use the built-in desktop zoom feature available on Mac and Windows 10.
Place the mouse cursor over the part of the image you want to enlarge, then:
- On Mac, spread two fingers apart on the trackpad,
- On Windows, hold down the Windows key and press the + key.

4- How does this application work?

A fine-tuned Faster R-CNN computer vision model analyzes each image. When opacities are detected, the model outputs their bounding box coordinates. These boxes are then drawn on the X-ray.

5- Which image formats are supported?

The application accepts images in dicom, png, or jpg format. Tiff images are not supported.

7- Do I need an internet connection for this application to work?

No, an internet connection is not required. However, an internet connection is required for the initial download and installation.

8- Will I need a computer with a GPU and a lot of RAM?

A GPU may make the application run faster, but it is not required. This application also runs properly on a CPU. You do not need a large amount of RAM either. A standard Mac or PC can run this application without any problems.

9- Will the application always be free?

Yes, it will always be free. This is an open-source project.
